# Selenium with Python – Learning Repository 🐍🤖

This repository is a personal learning tracker for **Selenium automation using Python**.  
It contains examples, exercises, and small projects created while learning browser automation and testing concepts with Selenium.

---

## 📌 Purpose

- Learn Selenium WebDriver using Python
- Practice browser automation and UI testing
- Understand test structure, locators, waits, and assertions
- Build confidence in writing automation scripts from scratch

---

## 🧰 Tech Stack

- **Python 3**
- **Selenium**
- **WebDriver** (ChromeDriver / GeckoDriver)
- (Optional) `pytest` for test execution
